# Network-Automation-Lab
- Virtual Environment including network automation projects listed:
    - GNS3 - Network management of nodes within a VMWare Enviornment
    - Cisco Modeling Lab - Simulation environment for network management controlled by a CML Controller on a web interface via port 9090
    - Python automation script to manage, modify and configure simulator environemt for CML and GNS3

- Enviornment and OS:
    - VMWare Workstation
    - Ubunut, GNS3, and CML
